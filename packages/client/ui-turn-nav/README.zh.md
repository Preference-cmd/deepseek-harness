# @deepseek-ai/dsh-client-ui-turn-nav

[English](README.md) | 中文

DeepSeek Harness Web GUI 中用于在已加载的对话轮次间跳转的轮次导航栏。

## 概述

本包提供一个垂直导航栏，显示在对话滚动区域旁边。它显示已加载的轮次编号，允许用户在对话轮次之间快速导航。

## 功能

- 自动检测对话 DOM 中的轮次标记
- 高亮当前可见的轮次
- 点击时平滑滚动到对应轮次
- 通过 MutationObserver 响应动态内容变化

## 模型体验

本包无模型相关影响，纯粹是 UI 导航辅助工具。

## 已知限制和待处理工作

- 超大对话历史（>100 轮）的性能尚未优化
- 轮次间的键盘导航尚未实现EOF
